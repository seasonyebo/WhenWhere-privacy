개인정보처리방침

시행일: 2026-06-29

문구 보완일: 2026-11-17

언제어디(이하 "앱")는 사용자의 프라이버시를 최우선으로 설계되었습니다. 이 방침은 앱이 어떤 정보를 다루는지, 어떻게 저장·사용하는지를 설명합니다.

1. 수집·사용하는 정보

  • 위치 정보: 하루 동선을 자동으로 기록하기 위해 사용합니다. 정지 중에는 저전력 이벤트(중요 위치 변경·방문)를 사용하고, 이동이 감지되면 이동 구간의 경로를 남기기 위해 정밀 위치를 추가로 수집하며, 앱을 보지 않을 때도 기록하려면 "항상 허용"이 필요합니다.
  • 사진과 카메라: 사진 보관함을 참조해 방문 사진을 표시합니다. 앱에서 직접 찍은 사진은 사용자 동작으로 시스템 사진 앱에 저장되고 선택한 방문에 첨부됩니다. 앱은 사진 파일을 외부 조회나 자체 서버로 보내지 않습니다. 직접 첨부한 사진의 보관함 식별자는 복원용 백업에 포함될 수 있습니다. 사진 앱의 동기화는 기기 설정을 따릅니다.
  • 음성 메모와 함께한 사람: 사용자가 녹음 버튼을 누를 때만 마이크를 사용합니다. 음성 파일과 사용자가 직접 입력한 동행인 이름은 이 기기에만 보관하며 앱의 백업이나 내보내기에 포함하지 않습니다. 키보드 받아쓰기를 사용해 저장한 텍스트는 일반 메모로 처리되며 받아쓰기 동작은 시스템 설정을 따릅니다.
  • 캘린더 접근(읽기 전용): 방문 시간과 겹치는 일정을 표시하기 위해 참조합니다.
  • 동작·피트니스: 운영체제가 제공하는 활동 종류·시각·신뢰도를 기기에 보존하여 신호대기와 방문을 구분하고 이동수단(도보·자전거·자동차)을 판별하는 근거로 사용합니다. 권한이 없거나 자료가 부족하면 활동을 확인하지 못한 상태로 처리합니다. 내보내기와 선택적 iCloud 백업에는 숨김 정책에 따라 내보낼 수 있는 활동 근거가 함께 포함될 수 있으며, 이 근거를 장소·날씨 조회 API에 보내지 않습니다.

2. 저장 위치

기록은 기본적으로 사용자의 기기에 저장됩니다. 당사는 기록을 수집·보관하는 서버를 운영하지 않으며, 별도의 앱 사용자 계정이나 회원가입도 없습니다. 외부 조회에 필요한 정보의 전송은 제3자 서비스 항목에, 선택적 iCloud 백업은 아래에 구분하여 설명합니다.

  • iCloud 백업(선택 기능): 기본값은 꺼짐이며, 사용자가 직접 켠 경우에만 동작하고 언제든 끌 수 있습니다.

iCloud 백업은 Pro 기능입니다. 사용자가 켜고 유효한 구독이 있을 때만 백업 파일이 사용자 본인의 Apple 계정에 속한 CloudKit 개인 저장 공간에 저장됩니다. 당사는 이 사본을 별도 서버로 가져오지 않습니다. 데이터는 전송 중과 서버에 저장된 상태에서 암호화됩니다. 표준 데이터 보호에서는 Apple이 복구에 필요한 키를 보관하며, 계정에서 '고급 데이터 보호'를 켜면 이 앱이 백업 본문에 사용하는 CloudKit 자산은 종단간 암호화됩니다. 보호 범위와 복구 조건은 Apple의 iCloud 보호 방식과 계정 설정을 따르며, 모든 설정에서 Apple도 접근할 수 없다고 보장하지 않습니다. 복원용 백업에는 위치·방문·이동 기록과 설정·교정·학습 정보가 포함될 수 있습니다. 직접 첨부한 사진은 보관함 식별자만 담기므로, 백업으로 사진 파일 자체를 복원할 수는 없습니다. 다른 이름으로 위장한 장소의 원래 좌표와 숨긴 항목은 백업에 포함되지 않습니다. 직접 내보낸 복원용 파일에는 앱이 별도 암호화를 적용하지 않습니다. 파일을 저장하거나 공유할 때는 내용을 볼 수 있는 사람을 확인해 주세요.

3. 제3자 서비스

  • 카카오 로컬 API: 장소명·주소 조회와 주변 장소·상호 검색에 사용합니다. 요청 종류에 따라 좌표, 검색어, 검색 반경·분류 등의 조건이 카카오로 전송됩니다. 장소 키워드 검색에는 검색어와 기준 좌표를, 주소 검색에는 주소 검색어를 보냅니다. 자동 장소 확인에도 건물명이나 도로명 같은 검색어를 사용할 수 있습니다. 이름·연락처·앱 사용자 계정 식별자를 별도 필드로 추가하지 않지만, 검색어에 사용자가 입력한 정보가 포함될 수 있습니다.
  • 애플 WeatherKit: 방문 시각의 날씨를 조회하기 위해 해당 좌표와 조회할 시각 범위가 Apple로 전송됩니다.
  • 애플 CLGeocoder: 해외 지역명을 조회할 때 해당 좌표가 Apple로 전송됩니다.
  • 애플 지도(MapKit): 지도 표시를 위해 Apple 지도 서비스를 이용하며 표시 영역 등 지도 요청 정보를 처리합니다. 지도·장소·날씨의 외부 조회에는 인터넷 연결이 필요합니다.

사진·캘린더 내용은 이 조회 API에 보내지 않습니다. 전체 동선·방문 기록 묶음을 조회 API에 업로드하지는 않지만, 조회에 필요한 개별 좌표·시각은 기록에서 가져와 전송할 수 있습니다. 선택적 iCloud 백업은 위 저장 위치 항목의 별도 기능입니다.

통신 과정에서 서비스 제공자가 IP 주소 등 연결 정보를 처리할 수 있습니다. 제공자의 보유·이용·삭제에는 각 서비스의 약관과 개인정보처리방침이 적용되며, 당사가 요청 정보의 미보관이나 즉시 삭제를 보장하지는 않습니다. 카카오 일반 방침의 모든 수집 항목이 이 앱의 Local API 요청에 그대로 적용된다는 뜻은 아닙니다. 카카오: https://www.kakao.com/policy/privacy · 개발자 서비스 보안 안내: https://developers.kakao.com/terms/ko/security · 연결된 비즈니스 파트너 방침: https://business.kakao.com/policy/privacy/ · Apple: https://www.apple.com/legal/privacy/

4. 추적·광고

앱은 사용자를 추적하지 않고, 광고를 게재하지 않으며, 분석 SDK로 행동을 수집하지 않습니다.

5. 데이터 보관 및 삭제

기기 내 기록은 사용자가 삭제하기 전까지 보관됩니다. 앱 안에서 개별 기록 삭제, 전체 데이터 삭제, '오래된 기록 정리'(기간이 지난 기록 자동 정리)를 설정할 수 있습니다. iOS의 '앱 삭제'는 이 기기의 앱과 앱 내 기록을 삭제하지만, '홈 화면에서 제거'나 '앱 정리하기'는 기록 삭제와 다릅니다.

앱 삭제나 iCloud 백업 끄기는 이미 저장된 iCloud 백업 사본을 삭제하지 않습니다. 기기 내 기록을 지운 것만으로 기존 iCloud 사본까지 삭제됐다고 볼 수 없습니다. iCloud 사본은 기기의 Apple 계정 > iCloud > 저장 공간 관리에서 해당 앱 데이터를 별도로 삭제해야 합니다(메뉴 이름은 OS 버전에 따라 다를 수 있습니다). 직접 내보낸 백업 파일과 운영체제의 기기 백업도 별도로 관리해야 합니다. 당사는 기록을 보관하는 서버가 없어 대신 삭제할 수 없으며, 제3자 조회 정보의 처리는 해당 제공자의 정책에 따릅니다.

6. 아동의 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동 전용 정보 수집 절차를 제공하지 않습니다. 기록 저장·외부 조회·선택적 iCloud 백업의 처리 범위는 위 항목과 같습니다.

7. 사용자의 권리

사용자는 언제든지 기록을 삭제하거나, 백업으로 내보내거나, 민감한 장소를 숨길 수 있습니다. 데이터의 주인은 사용자입니다.
